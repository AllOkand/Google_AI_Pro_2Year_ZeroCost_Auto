# Google AI Pro (5 ТБ) — 2 года с нулевыми затратами (US$0.00 -> 24 месяца) | Автоматическая панель управления

### I. Системные требования
* **ОС:** Windows 10 / 11 или Ubuntu / Linux Desktop (требуется графическая сессия: физический монитор или удаленный рабочий стол; для серверов с чистым CLI потребуется самостоятельно настроить виртуальный дисплей Xvfb, работа в таком режиме автором не тестировалась).
* **Браузер:** Установленный Google Chrome или Chromium (в Windows достаточно пути по умолчанию; в Linux поиск выполняется автоматически по путям в PATH, /usr/bin и др.; при установке в нестандартный каталог можно задать переменную окружения CHROME_PATH).
* **Python:** Версия 3.10 или выше (при установке на Windows обязательно отметьте галочку Add Python to PATH).
* **Сеть:** На компьютере должен работать прокси с регионом США (US) либо заполнен шаблон прокси в левой части панели управления.

---

### II. Быстрый запуск

**Для Windows:**
1. Первый запуск: дважды кликните по файлу `1_首次运行_安装依赖并启动.bat` (Установка зависимостей и запуск).
2. Дальнейшее использование: запускайте `2_启动控制台.bat` (Запуск консоли).
3. Браузер автоматически откроет страницу панели управления: http://127.0.0.1:8765

**Для Ubuntu / Linux:**
1. Первый запуск: выполните в терминале:
   chmod +x *.sh && ./1_首次运行_安装依赖并启动.sh
2. Дальнейшее использование: запускайте `./2_启动控制台.sh` (или напрямую `python3 app.py`).
3. Откройте панель управления в браузере по адресу: http://127.0.0.1:8765

### III. Настройка карты и инструкция по прогону аккаунтов

#### 1. Ввод платежной карты (обязательно):
В левой части страницы в блоке «Глобальная конфигурация и привязка карты без налога» введите данные зарубежной карты Visa или Mastercard:
* Номер карты (16 цифр)
* Срок действия (месяц / год, например 08 / 29)
* Код безопасности (3-значный CVC)
* Имя и фамилия держателя карты на латинице
* Почтовый индекс для безналогового штата уже заполнен по умолчанию: 97201 (штат Орегон, США), менять его не нужно.

После заполнения нажмите [💾 Сохранить конфигурацию].

⚠️ Предупреждение о безопасности: Файл config.json содержит реальные данные карты/CVC, пароли от аккаунтов и секретные ключи 2FA. Он добавлен в .gitignore и не отслеживается Git. Ни в коем случае не коммитьте и не передавайте этот файл третьим лицам; в репозитории должен оставаться только шаблон config.example.json без конфиденциальных данных.
Примечание: в скрипт встроен жесткий механизм защиты от списаний — подписка оформляется только в том случае, если в окне оплаты четко отображается сумма US$0.00.

#### 2. Массовый импорт аккаунтов Google:
В правой части веб-интерфейса в поле «Зона массового импорта аккаунтов» вставьте учетные записи (по одной на строку). Поддерживаются форматы:
* Логин----Пароль----Резервная_почта
* Логин----Пароль----Резервная_почта----Секретный_ключ_2FA
* Логин----Пароль----Секретный_ключ_2FA

Нажмите [➕ Импортировать список аккаунтов].

#### 3. Запуск автоматизации:
Нажмите [▶ Выполнить] напротив нужного аккаунта или [▶ Запустить массовое выполнение] в верхней части страницы.

Скрипт автоматически выполнит следующие шаги:
* Шаг 1: Автоматическая авторизация в Google с прохождением проверки по резервной почте или 2FA.
* Шаг 2: Привязка карты к безналоговому адресу + подключение первого бесплатного промо-пакета на 12 месяцев (US$0.00).
* Шаг 3: Наложение второго бесплатного пакета на 6 месяцев (US$0.00 -> 18 месяцев).
* Шаг 4: Наложение третьего бесплатного пакета на 6 месяцев (US$0.00 -> суммарно 24 месяца подписки).
* Шаг 5: Автоматический переход в Google Play для отмены автопродления, фиксация 2-летнего срока действия подписки и сохранение проверочного скриншота.

### IV. Доработки безопасности (в данном форке)

* Защита от списаний по принципу Fail-Closed: скрипт подтверждает подписку только при наличии точного совпадения суммы 0.00 с валютным символом (например, US$0.00). Если в любой части окна появляется любая ненулевая сумма (например, $10.00 или $19.99 со следующего месяца), операция немедленно блокируется, и клик по кнопке оформления не происходит.
* Маскирование логов: CVC-коды, динамические коды 2FA и учетные данные прокси больше не пишутся в лог в открытом виде (заменяются масками вида [***]).
* Отказ от подозрительных вызовов Win32 API: удален скрытый запуск браузера через системные Win32 API в отдельной интерактивной сессии рабочего стола (на который реагировали антивирусные эвристики). Теперь запуск Chrome выполняется через стандартный subprocess.
* Строгая валидация успеха: статус успеха выставляется только по официальной квитанции. Промежуточные экраны («Резервный способ оплаты», «Напомнить позже», «Понятно») больше не считаются завершением. Добавлена принудительная сверка реальной даты окончания подписки на странице Google Play (проверка идет на шагах 2, 3, 4 и 5; без подтверждения даты статус выполнения не присваивается).
* Защита интерфейса: в веб-панели пароли в списке аккаунтов больше не выводятся открытым текстом, а весь входящий текст экранируется перед отрисовкой для предотвращения XSS/инъекций.
* Изоляция служебных файлов: каталоги profiles/ (содержащие активные сессии и cookies) и screenshots/ добавлены в .gitignore.
  Внимание: если вы когда-либо пушили config.json с реальными данными в открытый репозиторий, немедленно перевыпустите карту, смените пароли и сбросьте 2FA — удаление файла последующим коммитом не стирает его из истории Git.
